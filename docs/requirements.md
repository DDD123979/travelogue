## 1. 定位与用户

「游迹」是面向自由行的攻略与行程工具：按类型发现目的地 → AI 生成逐日行程（高德校准交通）→ 社区分享游记。
**不做交易**：无预订、支付、订单、商家端。

目标用户：自由行游客（要现成行程）、规划新手（不想读长攻略）、内容分享者（发布游记获得反馈）。

## 2. 功能需求

### 2.1 已实现

| 模块 | 功能 | 规则 / 说明 |
|---|---|---|
| 账号 | 注册 / 登录 | 用户名唯一、密码 ≥ 6 位、BCrypt 存储 |
| 账号 | 登录保护 | 同账号连错 5 次锁 15 分钟；报错不区分账号是否存在 |
| 账号 | 会话 | UUID token 存 Redis（2 小时），退出即失效 |
| 账号 | 找回密码 | 6 位验证码，5 分钟有效、一次性 |
| 账号 | 个人资料 | 头像、独立昵称（可改）、密码（需原密码）；用户名与 8 位账号 ID 不可改 |
| 目的地 | 列表 / 详情 | 23 目的地、115 景点；分类筛选、关键词搜索、必去景点详解 |
| 目的地 | 类型浏览 | 全部 / 自然生态 / 人文古迹 / 街区市集 / 观景夜景 |
| 排行 | 热度榜 | 目的地榜、景点榜 |
| 参考行程 | 逐日展示 | 每天 2 个去处，标注上午 / 下午 / 晚上 |
| AI | 行程生成 | 按城市 + 天数 + 偏好，SSE 流式；失败给出明确提示 |
| AI | 交通接地 | 高德驾车耗时，缓存 7 天；失败降级为估算，不阻断生成 |
| 社区 | 发布 | 正文 ≤ 800 字，最多 4 张图（jpg/png/webp，单张 ≤ 25MB） |
| 社区 | 互动 | 点赞 / 收藏（一人一条、可取消）、评论（≤ 300 字） |
| 社区 | 通知 | 他人赞 / 藏 / 评时轮询提示；自己操作自己不通知 |
| 个人主页 | 统计 | 发布数、获赞、收到评论、被收藏 |
| 本地 | 偏好 | 收藏、字号缩放、封面图与动画开关（localStorage） |

### 2.3 关键流程

**登录与会话**：输入账号密码 → 查失败计数（≥5 拒绝）→ 校验 BCrypt（失败则 +1）→ 成功清零计数并签发 token（Redis 2h）→ 前端 localStorage 保存，请求带 `Authorization: Bearer` → 服务端反查用户名，无 token / 过期返回 401。

**发布分享**：登录 → 选目的地 + 写正文 → 逐张上传图片（服务端压缩并生成缩略图）→ 提交正文与图片地址 → 帖子插到列表顶部。

### 2.4 业务规则与边界

| 场景 | 规则 |
|---|---|
| 重复点赞 / 收藏 | 唯一索引保证一人一条，再次点击为取消 |
| 删除权限 | 仅能删除自己的帖子 / 评论；取消赞不产生通知 |
| 上传限制 | 仅 jpg / png / webp；超过 25MB 或类型不符直接拒绝 |
| 依赖故障 | Redis 故障：登录返回 503，缓存自动回源数据库；高德故障：用估算耗时继续生成 |
| 空状态 | 无内容时展示引导文案，不留空白区 |

## 3. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 首页可交互 ≤ 2s；列表接口 P95 ≤ 500ms；AI 首字 ≤ 3s |
| 容量 | 单机 1.6G 内存、JVM 堆 512MB；图片压缩后单张约 300KB |
| 安全 | 密码不可逆；登录限流；token 可吊销；上传类型与大小校验 |
| 兼容 | 桌面 / 移动端响应式；字号 85%–130% 可调 |
| 可用性 | 外部依赖不可用时主流程仍可用；每日 03:00 备份保留 7 天 |

## 4. 数据与外部依赖

**核心实体**：用户（账号 / 昵称 / 头像 / 账号 ID）、目的地（标签、景点）、帖子（正文 / 图片）、互动（点赞、收藏、评论、通知事件）。

| 外部接口 | 用途 | 约束 |
|---|---|---|
| DeepSeek Chat API | 生成行程 | SSE 流式；Key 仅存服务端 |
| 高德 Web 服务 API | 坐标、驾车耗时 | 并发 1；缓存 7 天；失败降级 |

| 未启用 HTTPS | 中 | 待域名与证书 |

## 6. 验收标准

- **功能**：2.1 全部功能在桌面与移动端可完成主流程，无阻断性缺陷。
- **安全**：库中无明文密码；未登录访问写接口返回 401；非法上传被拒绝。
- **降级**：停掉 Redis 浏览仍可用；清空高德 Key 行程仍能生成。
